# 변화 탐험실 · 고1을 위한 상미분과 편미분

미분을 아직 배우지 않은 학생이 **예상 → 관찰 → 숫자 확인 → 수식 연결** 순서로 변화율과 물리 현상을 탐구하는 웹 대시보드입니다. 기본 화면은 고1 수준의 기초 과정이며, 공명·카오스·충격파·유체역학은 별도 **심화 실험실**에서 선택합니다.

## 기초 학습 6단계

| 단계 | 생활 속 실험 | 알아볼 수학과 물리 |
|---|---|---|
| 1. 변화율 | 움직이는 자동차 | 거리 변화량 ÷ 시간 간격, 그래프의 기울기 |
| 2. 상미분의 출발 | 식어 가는 차 | 한 값의 시간 변화, 현재 값으로 다음 값 예측 |
| 3. 편미분의 출발 | 따뜻한 막대 | 위치를 고정한 시간 변화와 시간을 고정한 위치 변화 |
| 4. 두 번 미분 | 막대의 열 퍼짐 | 중앙 온도와 이웃 평균, 2차 공간미분 |
| 5. 두 번 미분과 물결 | 잡아당겼다 놓은 줄 | 위치 → 속도 → 가속도, 2차 시간미분 |
| 6. 2차원과 다음 탐구 | 넓은 금속판 | 좌우·위아래 이웃, 2차원과 2차 미분의 구별 |

각 단계는 재생·한 걸음 이동·시간 탐색, 수치 설명, 짧은 확인 질문을 제공합니다. 수식과 전문 용어는 펼쳐 보는 설명에 배치합니다. 기초 모형은 냉각의 전진 Euler, 열전도의 유한차분, 줄의 Velocity Verlet으로 계산합니다. 길이·온도·시간 단위와 경계 가정을 함께 표시합니다.

## 선택 심화 과정 · 9대 물리학 ODE & 유체역학 실험실

| 번호 | 구분 | 실험실 이름 | 지원 차원 | 핵심 물리 현상 및 수치해석 결합 포인트 |
| :---: | :---: | :--- | :---: | :--- |
| **01** | ODE · 역학 | **감쇠·강제 조화진동자와 공명** | 0D (시간·위상) | 관성·감쇠·복원력·외력 실시간 벡터 분해, 공명 곡선 $M(\omega_d/\omega_0)$, 맥놀이, Euler vs Verlet vs RK4 에너지 보존 비교 |
| **02** | ODE · 비선형 | **비선형 대각도 진자 & 자려 진동** | 0D (시간·위상) | $\sin\theta$ 비선형 진자 vs 소각도 선형 근사($\theta$) 주기 비교, 위상 평면 분리선(Separatrix), Van der Pol 극한주기궤도, Duffing 진동자 |
| **03** | ODE · 궤도/카오스 | **케플러 궤도 역학 & 로렌츠 열대류 카오스** | 2D / 3D | 케플러 타원 궤도의 각운동량 보존(Symplectic Verlet vs Euler), Rayleigh–Bénard 열대류 축소 모델인 로렌츠 3D 어트랙터와 나비효과 |
| **04** | **PDE · 파동/이류** | **파동·이류 결합 방정식 (Wave & Convection)** | **1D / 2D / 3D** | **1D·2D 시간에 따른 대류(Convection) 수송**, 회전 와류장 이류, **이류 매질 위의 파동(도플러 효과 및 초음속 마하 원뿔 $M = |\mathbf{U}_0|/c > 1$)**, Upwind vs Lax–Wendroff vs TVD MUSCL 동시 비교 |
| **05** | PDE · 열/물질 | **대류-확산 및 열전달 방정식** | **1D / 2D / 3D** | 이류항($-\mathbf{u}\cdot\nabla T$)과 확산항($\alpha\nabla^2 T$)의 경쟁, **페클레 수($\text{Pe} = uL/\alpha$)** 에 따른 열 플룸 형성, FTCS vs Crank–Nicolson 및 중앙차분 진동 한계 |
| **06** | PDE · 비선형 유동 | **비선형 Burgers 방정식** | **1D / 2D / 3D** | 비선형 자기 이류($\mathbf{u}\cdot\nabla\mathbf{u}$)에 의한 파면 가파름과 충격파 탄생, $x$–$t$ 특성선 교차, **보존형 FVM vs 비보존형 차분 충격파 속도 비교** |
| **07** | PDE · 자유수면 | **천수 방정식 (Shallow Water Equations)** | **1D / 2D / 3D** | 1D/2D 댐 붕괴(Dam Break), 수중 언덕 지형 $b(x,y)$에 의한 쓰나미 천수 변형, 배경 유속 대류 및 프루드 수($\text{Fr} = |\mathbf{u}|/\sqrt{gh}$) |
| **08** | PDE · 압축성 기체 | **압축성 Euler 방정식 (충격관 & 폭발파)** | **1D / 2D / 3D** | 1D Sod/강충격관 **엄밀 Riemann 해석해 오버레이**(팽창파·접촉 불연속면·충격파), **2D 원통 폭발파 및 가상 슐리렌($|\nabla\rho|$)** |
| **09** | PDE · 점성 유체 | **2D 비압축성 Navier–Stokes 스튜디오** | **2D / 1D / 3D** | 원기둥 장애물 후류 **카르만 와류열(Kármán Vortex Street)**, Kelvin–Helmholtz 전단 불안정성, Taylor–Green 엄밀해 검증, 압력 포아송 방정식 및 라그랑주 유체 입자 추적 |

## 🛠️ 주요 인터랙티브 기능

1. **[1D 단면 파형] ↔ [2D 평면 필드] ↔ [3D 입체 표면] 원터치 전환**:
   - 모든 공간 PDE 실험실에서 1D와 2D, 3D 시점을 즉시 오가며 차원 확장에 따른 대류·파동·확산 효과를 입체적으로 비교할 수 있습니다.
2. **실시간 미분항 ON/OFF 스위치 & 항별 기여도 분해기**:
   - 상단의 `[이류/대류항]`, `[확산/점성/파동항]`, `[비선형 대류항]`, `[파원/지형 원천항]` 칩을 터치해 방정식의 특정 항을 실시간으로 켜고 끌 수 있습니다.
   - `🔬 항별 분해·격자` 탭에서 선택한 프로브 격자점의 1차 기울기($\nabla f$), 2차 라플라시안 곡률($\nabla^2 f$), 그리고 각 미분항의 실시간 수치 크기와 스텐실(3점/5점)을 확인할 수 있습니다.
3. **캔버스 직접 터치/드래그 인터랙션**:
   - 스마트폰 화면이나 마우스로 시뮬레이션 캔버스를 터치/드래그하면 파원, 열원, 수면 물방울, 또는 소용돌이 제트와 염료를 유동장에 직접 주입할 수 있습니다.
4. **다중 수치기법 동시 비교 & 격자 수렴성 실험**:
   - `Upwind vs Lax–Wendroff vs TVD MUSCL`, `보존형 vs 비보존형`, `Euler vs Verlet vs RK4`를 한 화면에서 동시에 주행시켜 수치 확산(Numerical Diffusion)과 수치 분산(Numerical Dispersion)을 직관적으로 구분합니다.
