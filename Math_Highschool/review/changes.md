# Claude 리뷰 반영 기록

검토 도구: 실제 로컬 Claude Code CLI, 읽기 전용. 검토 모델은 원본 결과의 `modelUsage`에 기록된 `claude-opus-5-5`입니다. 1차 리뷰 원문은 [round-1.json](round-1.json)에 있습니다. 원문 이외의 계정·세션·비용 정보는 포함하지 않았습니다.

## 1차 리뷰 요청과 반영

| 지적 ID | 반영 내용 |
|---|---|
| VIS-VOLUME-2D | 넓이 직사각형을 제거하고 회전 원판 9개, 위아래 경계, 위치·반지름·단면 넓이 표를 표시. |
| VIS-LIMIT-PROBE | 현재 입력의 별도 점·값·접근 거리와 좌우 접근 수치 표 추가. |
| A11Y-SKIPLINK-ROUTE | 해시를 변경하지 않고 본문 포커스를 이동하여 레슨을 유지. |
| VIS-SYSTEM-MARKER | 실제 교점을 표시하고 입력 조절기가 없는 레슨의 임의 관찰점 제거. |
| VIS-INVERSE-ASPECT | 역함수 그래프의 x·y 단위 길이를 동일하게 설정. |
| VIS-FUNDAMENTAL-NOAREA | 누적 구간 음영, 누적 함수의 점과 접선 추가. |
| VIS-SERIES-PARTIALSUM | 각 항·부분합을 다른 색으로 표시하고 부분합·남은 차이 표 추가. |
| TABLE-DIFF-QUOTIENT | h와 함숫값 변화량, 평균 변화율의 접근 표 추가. |
| VIS-DERIVGRAPH | 원함수 접선·도함수 점·수치 열 추가, 선택 가능한 극단값까지 범위 확보. |
| A11Y-CONTRAST-SMALL | 정보 텍스트 최소 12px와 대비 강화. 모바일 입력은 16px로 설정. |
| VIS-SUBSTITUTE-CLIP | 치환적분의 음수 기여가 잘리지 않도록 y축 범위를 확장. |
| VIS-TRIG-PERIOD | 두 주기를 표시하고 π 눈금과 이동 방향을 명시. |
| FMT-SIGNED-FORMULA | 부호 표시 헬퍼를 사용하여 연속된 부호를 정리. |
| QUIZ-CHAIN-ORDER | 뒤에서 배우는 로그·지수 미분 문항을 합성함수의 안쪽 변화율 문항으로 교체. |
| QUIZ-SHARED-DISTRACTOR | 69개 개념별 두 번째 오개념을 작성. 첫 오답은 힌트, 재시도 때 이유를 제시. |
| UI-LEGEND-LABELS | 평균값정리 접점·라벨, 합성함수 범례, 독립 표 라벨, 탄젠트 점근선 보완. |
| DATA-CORRUPT-OVERWRITE | 손상 JSON 원문 백업, 백업 불가 시 덮어쓰기 중지, 미지 개념을 `_legacy`에 보존. |
| DOC-README-REVIEW | 리뷰 원문과 이 반영 기록 추가. |

추가 자체 점검: 물건 개수는 음수가 아닌 정수 점으로 표현하고, 합성함수 판독값에 현재 입력을 반영하며, 확률·수열의 가로 눈금을 정수로 표시했습니다.

검증: 수학·정의역·매개변수·리뷰 회귀 22개 검증 묶음, 69개 기본/최소/최대/혼합 설정, PC 1440px·모바일 390px의 전체 개념 조작과 저장·복원·다운로드가 통과했습니다. 원판·접근 수치·부분합·동일 축척·백업을 위한 회귀 검증도 추가했습니다.

이 변경 후 Claude에 재리뷰를 요청하여 최종 배포 여부를 확인합니다.

## 2차 리뷰 요청과 반영

원문: [round-2.json](round-2.json). 1차 지적 18개 모두 해결되었다는 확인을 받았습니다. 추가 지적 7개도 다음과 같이 반영했습니다.

| 지적 ID | 반영 내용 |
|---|---|
| VIS-DERIVATIVE-NEGATIVE-X | 미분 전용 x축 −2.5..3.5, y축 −2..13. 모든 그래프의 유한 관찰점이 범위 밖이면 축을 확장. |
| VIS-PROBE-OUT-OF-VIEW | 탄젠트 y축 ±6, 지수함수 x축 최대 3과 양끝 높이를 반영. |
| FMT-COEFFICIENT-COSMETIC | 계수 1·−1과 상수 0을 정리하는 표시 헬퍼. 역함수의 불필요한 괄호·분모 1 생략. |
| UI-LEGEND-DERIVGRAPH-FUNDAMENTAL | 원함수·도함수·접선·두 관찰점의 관계를 범례에 명시. |
| QUIZ-ATTEMPT-COUNT | 오답 전용 횟수로 첫 오답 힌트를 구분. 정답 후 첫 오답에도 힌트 제공. |
| DATA-BACKUP-REPEAT | 손상 원문의 백업 성공 후 원래 키를 빈 정상 기록으로 교체하여 중복 백업 방지. 실패하면 저장 중지. |
| A11Y-RESIDUAL-SMALL | 오개념 제목·분류·문항 번호·선택지 번호도 12px와 진한 색으로 변경. |

수치·내용·저장·그림 검증은 24개 묶음으로 확장했습니다. 그래프 전체의 기본/최소/최대/혼합 설정에서 circle 좌표가 실제 플롯 안에 있는지 검사하며, 모바일·PC 브라우저 검사도 조절기 최소와 최대를 모두 조작하도록 보완했습니다.
