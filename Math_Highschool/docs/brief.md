# 개념의 연결 — 독립 수능 수학 학습 프로젝트

## 사용자 요청
기존 69개 개념 탐험실을 수능 준비 고등학생의 실질적인 개념 학습에 도움이 되도록 다시 설계·구현. PDE_Dashboard와 연계하지 않는 독립 프로젝트. 기획 단계부터 실제 Claude와 논의하고 진행을 공개. 사용자에게 중간 선택·승인을 묻지 않고 진행.

## 출발점의 문제
기존 버전은 넓은 주제 목록과 짧은 정의·쉬운 3문항, 고정된 대표 그래프에 그침. 개념의 이유·조건·표현 전환·기본 적용·오류 분석·지연 인출 연결이 부족. 수능 연도 및 필수/범위 밖 구분이 약함. 코딩 리뷰 통과는 교육 효과 검증이 아님.

## 구현 제안(Claude 논의 전 초안)
- 기본 대상: 2028학년도 이후 공통 수능(2022 개정), 대수·미적분Ⅰ·확률과 통계. 2027 선택형은 별도 지원을 주장하지 않음.
- 공통수학은 필요한 선수 개념 진단·복습으로 연결. 미적분Ⅱ·기하·물리/PDE를 필수 경로에 넣지 않음.
- 각 주제는 필요성 → 유도/이유 → 조건/반례 → 말·식·표·그래프 연결 → 단계별 예제 → 기본/전이/오류 분석 → 설명 루브릭 → 나중에 다시 풀기.
- 문항은 정의 문장을 그대로 고르는 암기 문제에 의존하지 않음. 정답뿐 아니라 사고 오류별 피드백/선수 개념 연결. 첫 답변과 해설 후 재시도 구분. 정답 몇 개로 숙달 보증 금지.
- 실험은 적합한 개념에만 사용. 경우의 수는 실제 나열/경우표, 확률은 정확 확률과 모의실험 구분, 통계는 분포와 표집, 미분은 부호표와 원함수 연결.
- 기본 진단 12문항(점수 예측 없음), 학습 경로, 검색, 노트, 오답 재학습, 1/3/7일 후 복습, JSON 내보내기·불러오기. 로컬 저장 및 손상 백업. 기기 간 자동 동기화 없음.
- 각 과목 모든 대단원의 핵심 학습 목표와 구체 레슨을 명시하는 coverage 표. 핵심 개념 경로 완성하되 모든 기출 유형/성취기준 숙달 보증 금지.
- 인터넷 의존 없는 단일 HTML + 독립 소스/검증/설계문서. 모바일/키보드/수식 표현 우선.
