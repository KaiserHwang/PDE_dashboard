# 대표 레슨 검토 반영

실제 Claude 독립 검토(01)는 C11/P8/B5/B7/B9의 고정 수치·구간·집합·유리수 답을 손으로 확인해 오류가 없다고 기록했습니다. 실행은 Codex가 담당하며, Claude가 테스트를 실행했다고 표시하지 않습니다.

- S1: 날짜 전 연습 목록 분리. 144개 씨앗의 실제 문항 지문/정답 지문으로 새로움을 판단. 소진 시 가장 오래된 변형을 재사용해 일정은 이어가되 새 독립 증거로 세지 않음.
- S2: 날짜 전 시작한 미제출 연습을 복습 날짜 뒤에 독립 복습으로 재활용하지 않음. 내용 페이지를 열면 진행 중 복습은 도움 사용으로 기록.
- S3: 숫자 중간 공백을 삭제해 다른 숫자로 만들던 문제 해결. 집합은 공백/쉼표 분리. Unicode 음수/무한대 허용. 형식 오류는 채점 전에 안내하며 기록하지 않음.
- S4: 연속 실패3회·같은 오개념 신호2회이면 연결 선수 개념을 제안. 연속3회 실패 일정2일 뒤.
- S5: 실제 부호표·증가/감소·극대/극소/극값 없음, 판별식·교점 관계를 표시.
- G1(재검토02): 15개 확장용 복습 템플릿의 단일 매개변수 문제를 수정. 전체65개 템플릿에 실제 문항쌍40개 이상 검사 추가. 2쌍짜리 가짜 생성기로 실제 소진·재사용·일정 진행·지연 증거 제외를 확인.

최종 재검토 판정은 별도 원문에 기록합니다. 실제 교사 검토와 학생 대상 학습 효과 검증은 하지 않았습니다.
