# 과목 확장 검토 기준

대표 레슨은 실제 Claude 검토01 → 수정 → 재검토02 → 수정 → 확장관문04의 ACCEPT를 거쳤습니다.

확장 내용은 작성 세션과 다른 실제 Claude 세션에서 검토합니다. 핵심은 각 문항의 정답·조건·반례·전이 여부·대표 그림의 실제 모델 일치입니다. 정답 자체를 채점기에 넣어 통과시키는 검사는 수학 검산이 아니므로, 계산 가능한 복습 생성기는 별도 독립 계산/전수나열을 추가하고 고정 문항은 내용 검토로 확인합니다.

- 모든65개 레슨: 전체 필드/선수 관계/수식 구문/경계설정/실행 화면.
- 핵심55개: 적용8문항(기본2, 전이2, 오류위치·이유·수정, 결함설명판단), 별도 선수2·빈단계1.
- 선수10개: 적용4문항, 별도 선수2·빈단계1.
- 교육과정 대조: 공식 별책8과 원문 대조한 성취기준54개와 레슨 간 대응. 교과서 전체 예제와 기출 유형의 완전 포괄을 뜻하지 않음.
- 2028 공통 수능 개념 학습의 보조 과정. 고난도 기출훈련/실전시간관리/등급예측은 아님.
- 교사 검토·실제 학생 학습효과 검증은 없음. 이 제한은 앱과문서에명시.
