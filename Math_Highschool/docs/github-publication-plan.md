# 기존 공개 주소 업데이트 계획

독립 앱 개발 소스는 Suneung_Math에 있습니다. 사용자가 이미 이용하는 GitHub Pages의 Math_Highschool 폴더를 새 앱으로 업데이트합니다.

- 공개 주소: https://kaiserhwang.github.io/PDE_dashboard/Math_Highschool/
- 앱 코드·학습 경로·기록은 PDE 앱에서 독립되어 있습니다.
- 내용 검토를 마친 동일 소스를 동기화하고 Node22/npm ci/릴리스 검증/빌드를 실행합니다.
- Pages 산출물에는 Git 추적 파일과 dist만 포함하며 node_modules는 제외합니다.
- 기존 math.html과 소문자 별칭은 현재 Math_Highschool로 연결됩니다.
- GitHub push와 공개 HTML의 빌드 번호 일치를 각각 확인합니다.

독립 호스팅 Site도 이미 등록되어 있으므로 동일 소스의 소유자 전용 Site판을 정식 소스 저장·배포 절차로 게시합니다. 일반 공개 주소 안내는 위 GitHub Pages를 사용합니다.
